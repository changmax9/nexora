# Nexora 1.0.2

This update adds per-domain specific-node routing, introduces native Liquid
Glass broadcast announcements, and upgrades update check prompts to unified
in-window Liquid Glass modals.

## New

- **Pin websites to a specific proxy node or group**: in **Routing**, domain
  rules now support **Specific Node** alongside **VPN** and **Direct**.
  - Supports static profile nodes, proxy groups, and provider-supplied nodes
    (including node names containing commas or regex metacharacters via
    automatically managed hidden bridge groups that stay out of the main
    Proxies list).
  - Orders generated `DOMAIN-SUFFIX` overrides from deepest subdomain to parent
    domain so subdomain rules take precedence.
  - Adds a Liquid Glass target picker for inline editing of existing rules,
    missing-node warnings when a pinned target is absent from the active
    profile, node-name search filtering, and a banner to switch back to Rule
    mode when another outbound mode is active.
- **Liquid Glass broadcast announcements**: Nexora can now fetch and display
  remote announcements in an in-window Liquid Glass modal with localized copy,
  category badges, optional action links, active date windows, version
  targeting, and `once` / `daily` dismissal policies.
  - Refreshes silently on launch, VPN connection, and system wake with a
    30-minute cooldown after successful fetches and silent offline fallback.
  - Active announcements can be revisited anytime from **Settings → About →
    Announcement**.
  - Includes `script/announce.py` and `docs/announcements.md` for publishing,
    inspecting, or withdrawing announcements on the orphan `announcements`
    branch without modifying `main`.

## Improvements and fixes

- **Unified Liquid Glass update dialogs**: manual **Check for Updates** results
  now present in the same window-centered Liquid Glass modal as announcements,
  blocking background interaction and accessibility pass-through while open.
- **Centered modal presentation**: modals now render in a full-window overlay
  ignoring the unified titlebar safe area so dialogs stay geometrically
  centered.
- **Liquid Glass button hit-testing and accessibility**: stabilized hover and
  press transforms on Liquid Glass buttons so the hit target stays aligned with
  laid-out bounds, and added accessibility labels and selection traits to the
  sidebar navigation rail.

## Install and updates

For Apple Silicon Macs running macOS 15 or later. Existing installations
receive this release automatically through the Sparkle update feed; profiles,
proxy selections, routing overrides, and preferences are retained.

This community build is signed with an Apple Development certificate shared
across the app, bundled Mihomo core, and TUN helper, and the update feed
includes a Sparkle EdDSA signature for the DMG.
