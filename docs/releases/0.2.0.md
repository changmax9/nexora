# Nexora 0.2.0

This release adds adjustable native glass appearance and a new app icon, improves menu bar quick access and navigation, and includes the signed TUN helper introduced after 0.1.5. The Sparkle build number now increases with the app version.

## Install

This DMG is for Apple Silicon Macs running macOS 15 or later. Drag Nexora to Applications. This community build is signed with an Apple Development certificate and is not notarized. After trying to open it, go to **System Settings → Privacy & Security → Open Anyway** and confirm. This manual step is required because macOS does not accept the development certificate for ordinary public distribution.

To use TUN, turn it on in Nexora and approve the helper in **System Settings → General → Login Items & Extensions** if macOS asks. Administrator approval is required. Ordinary proxy mode does not need TUN approval. TUN has been verified on the development Mac; installation on another Mac has not been verified.

The DMG and update feed are signed separately: the app, bundled Mihomo, and TUN helper share one Apple signing team, while Sparkle verifies update downloads with an EdDSA signature. Source archives are attached below.
