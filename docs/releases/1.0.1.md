# Nexora 1.0.1

This update fixes TUN activation after upgrading Nexora and adds an explicit
update check button in Settings.

## Fixes

- **TUN helper upgrade resilience**: `NexoraTUNHelper` now caches its signing
  identity at launch, exits cleanly when idle, and steps aside immediately if
  its executable on disk is replaced by a newer app bundle.
- **Automatic XPC recovery**: when enabling TUN after an app update, Nexora
  retries interrupted XPC connections and automatically refreshes the
  `SMAppService` daemon registration if an earlier helper process rejects the
  connection, preventing `Couldn't communicate with a helper application.`
  failures.

## Improvements

- **Check for Updates in Settings**: added a compact Liquid Glass **Check for
  Updates** button next to the version number under **Settings → About**.
  - When a newer version is available, Nexora presents a confirmation dialog
    showing the current and latest versions with an option to launch Sparkle's
    automatic updater.
  - When running the newest release, Nexora presents a formal confirmation
    indicating that the current version is already up to date.

## Install and updates

For Apple Silicon Macs running macOS 15 or later. Existing installations
receive this update automatically through the Sparkle feed; profiles, proxy
selections, and preferences are retained. If an existing installation updated
from `0.2.2` to `1.0.0` before this release and still holds an older
`NexoraTUNHelper` process in memory, toggling Nexora off and on once in
**System Settings → General → Login Items & Extensions** (or running
`sudo launchctl kickstart -k system/com.maxchang.Nexora.TUNHelper`) will allow
it to pick up the `1.0.1` helper cleanly.
