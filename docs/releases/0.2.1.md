# Nexora 0.2.1

This release improves configuration imports, quota display, runtime reliability, and resource usage.

## Changes

- Read available quota metadata from local YAML files and subscription responses. Clearly distinguish saved snapshots from provider data, and explain when quota information is unavailable.
- Add quota refresh with duplicate-request protection and retain the last valid snapshot when a refresh fails.
- Support UTF-8 subscription filenames without a YAML extension, and show a clear error when a server returns a health message or an invalid configuration.
- Make managed configuration imports and deletion safer when saving the registry fails.
- Identify the app's own controller listeners correctly in Network Doctor and prevent duplicate diagnostic runs.
- Stop remaining latency-test batches when the configuration changes, and handle cancellation without a false failure message.
- Back off when traffic streams end or fail, and retain only the latest pending traffic update.
- Drain validation output while the core is running to prevent large-output deadlocks. Keep a bounded log tail in memory while preserving the full log file.
- Reuse connection rows across refreshes, create rows on demand, and pause runtime polling when the core is stopped.
- Use optimized builds for normal launches and app bundles; retain Debug builds for the debugger.

## Install and updates

For Apple Silicon Macs running macOS 15 or later. Drag Nexora to Applications. This community build is signed with an Apple Development certificate and is not notarized; macOS may require **System Settings → Privacy & Security → Open Anyway**. TUN requires approval in **System Settings → General → Login Items & Extensions** when prompted.

The app, bundled Mihomo, and TUN helper share an Apple signing team. The update feed includes a Sparkle EdDSA signature for the DMG. Existing installations can discover this release through their configured update feed.

The source archive contains project files and synthetic test fixtures. Personal configurations, subscription credentials, local logs, and private audit records are excluded.
