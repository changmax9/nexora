公告与检查更新

  • 阅读长公告时，只有正文会滚动。标题、右上角的关闭按钮和底部操作按钮始终留在原位。短公告会按内容高度显示。
  • 很长的公告标题最多显示三行，悬停可查看全文。检查更新时，较长的更新按钮文字可以换行。
  • 修复了部分翻译缺失时公告会混用语言的问题。例如，繁体中文公告只提供了标题时，正文会优先使用公告已有的中文翻译。

Announcements and update checks

  • Only the message scrolls in long dialogs. The title, close button, and actions stay in place. Short messages fit their content.
  • Long titles use up to three lines. Hover over a title to read it in full. Long update button labels can wrap.
  • Partially translated announcements now use the available language translation for each missing field before falling back to the default text.

适用于 macOS 15 或更高版本的 Apple 芯片 Mac。可在 Nexora 的「设置 → 检查更新」中升级，或下载 Nexora-1.1.1.dmg 安装。

For Apple Silicon Macs running macOS 15 or later. This community build is signed with an Apple Development certificate and has not been notarized by Apple.
