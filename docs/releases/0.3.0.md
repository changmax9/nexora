# Nexora 0.3.0

This release adds website and diagnostic tools, Siri and Shortcuts actions, and
updates the bundled core. It also improves configuration handling, process
cleanup, and recovery from a stalled core.

## New

- **Website connection comparison** (Diagnostics): compare a direct request with
  the current Nexora route for one HTTP(S) address without disconnecting. Results
  separate DNS, connection, TLS, timeout and HTTP responses. Addresses and
  results are kept in memory only.
- **Diagnostic explanation**: after running Diagnostics, a card summarizes the
  evidence and suggests next steps. On eligible Macs, an optional on-device
  Apple Intelligence summary can be requested; it only receives status flags and
  counts, never addresses, node names or subscription content.
- **Siri and Shortcuts**: connect, disconnect, enable or disable TUN, and select
  a proxy node. Selecting a node never enables the VPN by itself, and TUN still
  requires macOS administrator approval.

## Improvements and fixes

- Update Mihomo from v1.19.27 to v1.19.34, Sparkle from 2.9.3 to 2.10.1, and
  Yams from 5.1.3 to 6.2.2.
- Monitor the controller in the background, including when the main window is
  closed. Restart a stalled core at most once per minute; on repeated failure,
  stop and restore the system proxy instead of looping.
- Read provider-owned proxy metadata and use the provider health-check API for
  node latency tests, retaining compatibility with older controllers.
- Parse configuration values as YAML, including inline comments, IPv6 controller
  addresses, flow collections, anchors and merged defaults.
- Keep legacy subscriptions usable by omitting misplaced-plus DNS policy entries
  that never matched ordinary hostnames in the old core. The original source
  files and valid DNS policies are retained.
- Add routing overrides without corrupting unindented or flow-style rule lists.
  Validate candidate runtime changes before saving rules or stopping a connection.
- Wait for the core to exit before releasing its process and PID file, with a
  bounded graceful shutdown and a forced-exit fallback. Preserve the actual error
  when the core exits unexpectedly.
- Reserve distinct ports for the proxy, controller and DNS listeners, and avoid
  duplicate HTTP/SOCKS listeners next to the managed mixed listener.
- Limit core log files to 4 MiB each (current and previous).
- Show update reminders in the Update capsule when an application window is
  available; otherwise keep Sparkle's standard prompt.
- Verify downloaded core checksums and versions in a staging directory, then
  replace the existing binary atomically.

## Install and updates

For Apple Silicon Macs running macOS 15 or later. Drag Nexora to Applications.
This community build is signed with an Apple Development certificate and is not
notarized; macOS may require **System Settings → Privacy & Security → Open
Anyway**. TUN requires administrator approval when prompted.

The app, bundled Mihomo and TUN helper share an Apple signing team. Existing
installations receive this release through the Sparkle update feed; profiles
and preferences are retained.
