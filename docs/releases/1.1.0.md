# Nexora 1.1.0

Announcement and update dialogs now fade in and lift gently into place. Closing a dialog uses a shorter fade. Turning on Reduce Motion in Nexora or macOS switches both transitions to a simple fade.

- Long announcements scroll while the action buttons stay visible. Long action labels can wrap onto a second line, and hovering over the link shows its full text.
- Nexora now enforces the 64 KiB announcement size limit as it reads the feed, including when the server omits the content length.

## Install and update

For Apple Silicon Macs running macOS 15 or later. Open **Settings → Check for Updates** in an existing installation, or download **Nexora-1.1.0.dmg** for a fresh install.

This community build uses an Apple Development certificate and has not been notarized by Apple. The app, Mihomo core, and TUN helper share the same signing team. Sparkle verifies updates using the project's EdDSA key.
