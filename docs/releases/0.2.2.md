# Nexora 0.2.2

This release updates the bundled core and fixes configuration handling,
process cleanup, proxy recovery, and update reminders.

## Changes

- Update Mihomo from v1.19.27 to v1.19.33 and Sparkle from 2.9.3 to 2.10.0.
- Read provider-owned proxy metadata and use the provider healthcheck API for
  node latency tests, retaining compatibility with older controllers.
- Parse configuration values as YAML, including inline comments, IPv6 controller
  addresses, flow collections, anchors, and merged defaults.
- Keep legacy subscriptions usable by omitting misplaced-plus DNS policy entries
  that never matched ordinary hostnames in the old core. Apply the same
  compatibility during import and validation; retain the original source files
  and valid DNS policies without widening wildcard matches.
- Add routing overrides without corrupting unindented or flow-style rule lists.
  Validate candidate runtime changes before saving rules or stopping a connection.
- Wait for the core to exit before releasing its process and PID file, with a
  bounded graceful shutdown and a forced-exit fallback.
- Preserve the actual error when the core exits unexpectedly.
- Require a system proxy snapshot before changing settings, restore the original
  network service, and roll back a partially failed proxy enable operation.
- Wire scheduled updates to the Update capsule when an application window is
  available; retain Sparkle's presentation when no window can host the reminder.
- Verify downloaded core checksums and versions in a staging directory, then
  replace the existing binary atomically after all checks succeed.

## Install and updates

For Apple Silicon Macs running macOS 15 or later. The app, bundled core, and TUN
helper must share the same Apple signing team. Existing profiles and preferences
are retained when replacing the app bundle.

Community builds use Apple Development signing and are not notarized. TUN
requires macOS administrator approval when prompted. Public Sparkle distribution
also requires a signed appcast matching the released DMG.
