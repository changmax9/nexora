# Nexora 0.2.2

Disconnecting or quitting could leave browsers using a stopped local proxy on macOS. Nexora now saves the original settings for the selected network service before enabling its proxy. It restores HTTP, HTTPS and SOCKS settings and verifies them before stopping the core. If cleanup fails, the core stays available and you can retry Disconnect or Quit. After an unexpected app exit, reopening Nexora retries recovery.

If a previous version has already left you offline, open System Settings → Network → your active connection → Details → Proxies. If an enabled HTTP, HTTPS or SOCKS entry still points to Nexora’s stopped local address and port, turn that entry off. Keep any proxy supplied by your school, employer or another app.
